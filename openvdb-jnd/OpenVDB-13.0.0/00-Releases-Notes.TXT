Version 14.0.0 - October 29, 2026

Build:

OpenVDB:
nanobind 2.5.0 (makedepends)
Removed the Log4cplus dependency
Removed the FindBlosc.cmake module and the BLOSC_ROOT, BLOSC_INCLUDEDIR and BLOSC_LIBRARYDIR inputs. The USE_BLOSC option is deprecated and has no effect.
Added Zstd as an optional dependency of the OpenVDB core library, with the new USE_ZSTD CMake option (ON by default)

NanoVDB:
Standalone NanoVDB builds now install headers to the CMAKE_INSTALL_PREFIX include directory instead of /nanovdb.
